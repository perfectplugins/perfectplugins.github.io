// Why Perfect Plugins

Built Different

Lightweight

Event-driven architecture. No heavy tick loops unless needed. Minimal server impact.

Plug & Play

Drop the JAR, start the server. Config files auto-generate. Zero setup required.

Persistent

All data saved to JSON. Survives restarts, crashes, and updates. No database needed.

Custom Assets

Every plugin includes its own models, textures, icons, and particles. No external dependencies.

Admin UI

In-game admin panels with clean flat layouts. Manage everything without editing files.

Multi-language

Plugin messages in 6 languages (EN, FR, ES, DE, IT, PT). Full game translation available.
