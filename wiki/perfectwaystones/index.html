PerfectWaystones

Place waystones around your world, discover them and travel between them. Admins set up server waystones for everyone, players place their own, public or private. Travel can cost Waystone Orbs or money, wait a few seconds and have a cooldown. Found waystones show on the world map. There are 62 waystones in 10 styles.

Installation

  1. Stop the server and put PerfectWaystones-2.0.0.jar in your mods folder (in place of the old jar if you are updating).
  2. Start the server.
  3. Type /pws give blue and place the waystone. Its settings window opens.
  4. Place a second one somewhere else and use it (F) to start travelling.

How It Works

  1. Get a waystone with /pws give (add a name, e.g. /pws give red_oak) or craft it, and place it.
  2. Admins create server waystones for everyone; players create their own.
  3. Press F on a waystone to find it and open the travel menu.
  4. Pick any waystone you can reach and travel.

Server & Player Waystones

  • Server waystones: placed by an admin (perfectwaystones.admin), who chooses in the settings window whether a waystone is a server waystone or his own. Visible to everyone.
  • Player waystones: placed by a player, owned by him, public or private, managed from the settings window. Player waystones are capped at 10 orbs and 300 seconds of cooldown (config.json) so nobody can lock visitors out.
  • You can limit how many waystones a player may place, and give ranks their own limit (see Configuration).
  • Only the owner and admins can break a waystone. A stone waystone is broken with a pickaxe, an oak one with an axe.

Discovery

Every player keeps his own list of found waystones. A "Waystone discovered" title shows when you find one. Public player waystones appear once found; private ones are for their owner only. Server waystones are visible to everyone unless serverWaystonesNeedDiscovery is on (off by default). Found waystones show on the world map (showOnMap).

Travel Menu

Opened with F on a waystone. Filters on the left: All, Favorites, Mine, Server and one entry per world. Search and sort (nearest first or A to Z) on top, eight destinations per page. Each row shows the colour of the waystone, its distance (or its world), the trip cost and the cooldown. A destination you cannot reach right now is greyed out and says why: cooldown, missing orbs or money, world not loaded.

You arrive in front of the waystone, looking at it, on free ground, whatever its height.

Settings Window

Opens when you place a waystone, and from the Settings button of the waystone you stand at (owner and admins). It has the name (24 characters at most), public or private, orb cost and cooldown with + and - buttons, how many players found it, and Pick up waystone, which gives the block back. Admins also set the money price and the server toggle.

Costs, Cooldown & Warmup

  • Orbs: each waystone can ask for Waystone Orbs per trip.
  • Money: optional price per waystone, set by admins. Paid with PerfectEconomy, Ecotale or EliteEssentials when one is installed, otherwise with an item (gold bars by default).
  • Cooldown: per waystone, in seconds. Leaving the server does not reset it.
  • Warmup: warmupSeconds for the whole server (0 by default). A countdown "TRAVELLING TO" shows under the crosshair. Moving or taking a hit cancels the trip.

Orbs and money are taken when you really leave, after the warmup. A cancelled trip costs nothing, and starting a second trip cancels the first.

Crafting

  • Waystone Orb: 1 Void Essence + 1 Life Essence = 4 orbs, at a workbench.
  • Classic waystone (stone or oak): 2 Smooth Stone Brick Half + 10 Smooth Stone Brick + 10 Void Essence, at a workbench.
  • New families: each has a recipe in its own theme (gems, ice, rune shards, rope and shells, tree sap, an iron lantern, iron and copper bars, charcoal) plus 10 Void Essence, at a workbench.

Admin Panel

/pws admin has three tabs:

  • Waystones: every waystone, private ones too, with filters (All, Server, Players, Private, Missing) and search. Go there for free, edit or delete any of them (with a confirmation), check for waystones whose block is gone and remove them.
  • Settings: config.json edited in game, with Revert and Save and a line that says "Unsaved changes." or "Same as the file on the server."
  • Tools: pick a family, then the waystone to give yourself, or orbs; reload the files.

Cross-World Travel

Waystones store their own world, so you can travel between worlds. A destination whose world is not loaded is refused instead of sending you to the same coordinates in your current world.

Commands

Players have no command: they place a waystone and press F. /pws is for admins; give and orb also work from the console (quest and shop rewards).

CommandDescription
/pws adminOpen the admin panel
/pws give <waystone> [player] [amount]Give a waystone (blue, red_oak, crystal_ruby, cairn_frost, pillar_black_iron...). A wrong name lists them, family by family
/pws orb [amount] [player]Give Waystone Orbs
/pws listList every waystone of the server
/pws reloadReload config.json and the data files
/pws setlangOnly says that the plugin follows each player's game language
/pws helpShow help

Permissions

use and place are given to everyone; take them away with -perfectwaystones.use or -perfectwaystones.place.

PermissionDescription
perfectwaystones.useUse waystones (everyone by default)
perfectwaystones.placePlace waystones (everyone by default)
perfectwaystones.admin/pws, admin panel, server waystones, break and edit any waystone, no limits
perfectwaystones.bypass.costTravel without orbs or money
perfectwaystones.bypass.cooldownNo cooldown
perfectwaystones.bypass.warmupNo warmup
perfectwaystones.limit.<rank>The waystone limit of that rank

Configuration

File: config.json in the plugin's data folder (mods/KatsuyaTV_PerfectWaystones). Waystones are in waystones.json; discoveries and favorites are per player in the same folder.

{
  "dataVersion": 2,
  "warmupSeconds": 0,
  "cancelOnMove": true,
  "cancelOnHit": true,
  "effects": true,
  "particle": "Teleport",
  "sound": "SFX_Portal_Neutral_Teleport_Local",
  "orbItemId": "Waystonium_Orb",
  "serverWaystonesNeedDiscovery": false,
  "showOnMap": true,
  "playerWaystones": {
    "maxOrbCost": 10,
    "maxCooldownSeconds": 300,
    "limit": 0,
    "limitsByRank": { "vip": 10 }
  },
  "economy": {
    "provider": "auto",
    "itemCurrency": { "itemId": "Ingredient_Bar_Gold", "displayName": "Gold", "symbol": "G" }
  }
}

limit 0 = no limit. limitsByRank pairs with the permission perfectwaystones.limit.<rank>. economy.provider is auto, perfecteconomy, ecotale, eliteessentials or items.

Updating from 1.x

  • Waystones, discoveries and favorites are kept. On the first start the data folder is copied to backup-1.x-<date> and config.json is rewritten with all the new settings.
  • Player waystones above the new limits (10 orbs, 300 seconds) are brought down to them; the console says how many.
  • German and Italian are gone: the game does not have them. The old lang setting is no longer used.

FAQ

Why can't I see a waystone in the travel menu?

Player waystones have to be found first, by pressing F on them. Private waystones you do not own never appear.

Can players place their own waystones?

Yes, unless you take away perfectwaystones.place. Only admins create server waystones.

Who can break a waystone?

The owner, or an admin. Server waystones can only be removed by an admin.

I broke a waystone with a world edit and it is still in the list.

It is removed the first time someone tries to travel to it. You can also use the Missing filter of the admin panel and remove them all.

How do I give waystones or orbs as a quest reward?

Run pws give <waystone> <player> <amount> or pws orb <amount> <player> from any plugin that can run a console command.
