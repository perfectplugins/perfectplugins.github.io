PerfectEconomy

Version2.0.0
PriceFree
PlatformHytale Server Plugin
LanguagesEN, FR, ES, DE, IT, PT
DependenciesNone

The free money base of the PerfectPlugins series: wallets, several currencies, a bank with daily interest, paper bank notes, transaction history, a leaderboard, an admin panel, and an API and placeholders for other plugins. PerfectJobs, PerfectNPC, PerfectSellChest and PerfectOneBlock use it; PerfectShop (coming soon) will too.

Installation

  1. Drop PerfectEconomy-2.0.0.jar into your server's mods/ folder
  2. Start or restart the server
  3. Config files are generated on first run
  4. Players use /money; admins use /eco

Updating from 1.x: replace the jar. Balances, shop and settings are converted automatically on the first start; a copy of every file is kept in backups/before_2.0_<date>/.

Features

  • /money page: Wallet, History, Send, Top, Bank, Notes
  • Several currencies: id, name, symbol, format, decimals, starting balance, one default
  • Bank with daily interest (rate, daily cap, bank limit, payout hour, minimum balance)
  • Bank notes: paper notes to give or trade, cashed with a right-click; copies pay nothing; minimum, maximum and fee configurable
  • Transaction history with reason and source plugin; small payments from the same plugin are grouped
  • Leaderboard per currency (wallet + bank, configurable)
  • Admin panel: any player, online or not; give / take / set with a reason; reset; edit currencies, bank, notes, history
  • Atomic operations and crash-safe saves; every player gets an account on join
  • Cross-plugin API and placeholders
  • 6 languages with runtime switching

What happened to /shop?

The small built-in /shop was removed in 2.0. Selling and buying now belong to PerfectShop (server shop, auction house, player shops), which is coming soon and imports your old shop.json. The file is kept untouched and its sell prices remain readable through EconomyAPI.getSellPrice(itemId).

API for Developers

Static methods of fr.katsuyatv.perfecteconomy.EconomyAPI:

MethodDescription
getBalance(UUID), deposit(UUID, double), withdraw(UUID, double), setBalance(UUID, double)Default currency (1.x API, unchanged)
format(double), getSymbol(), getCurrencyName(), getSellPrice(String)Formatting and legacy shop prices
getCurrencies(), hasCurrency(c), getDefaultCurrency()List currencies
getBalance(UUID, c), getBankBalance(UUID, c), has(UUID, c, amount)Read balances
deposit(UUID, c, amount, reason), withdraw(...), setBalance(...)Change a balance with a reason for the history
transfer(from, to, c, amount, reason)Atomic transfer
format(c, amount), getCurrencySymbol(c), getCurrencyName(c)Per-currency formatting
isAvailable(), getVersion(), resolvePlaceholders(UUID, text)Utilities
// Soft integration through reflection
Class<?> api = Class.forName("fr.katsuyatv.perfecteconomy.EconomyAPI");
Method m = api.getMethod("getBalance", UUID.class);

Configuration

Files are stored in UserData/Saves/MODDING/mods/KatsuyaTV_PerfectEconomy/: currencies.json, economy.json, history.json, notes.json, config.json, and the legacy shop.json. Most settings are edited in game from /eco.

config.json

{
  "lang": "EN",
  "historyPerPlayer": 50,
  "baltopIncludesBank": true,
  "payMinimum": 0,
  "bank": { "enabled": true, "interestPercent": 1.0, "maxInterestPerDay": 1000,
            "maxBankBalance": 0, "payoutHour": 0, "minBalanceForInterest": 0 },
  "notes": { "enabled": true, "minimum": 10, "maximum": 0, "feePercent": 0 }
}

FAQ

Is PerfectEconomy really free?

Yes, since 2.0.0. It is the money base the other PerfectPlugins plug into.

Can I add more currencies?

Yes: /eco, Currencies tab. Each has its own id, name, symbol, format, decimals and starting balance.

Can players duplicate a bank note?

No. Every note has an id registered on the server: a copied note pays nothing and is removed.

Do my other plugins need an update?

No. The 1.x API is unchanged: PerfectJobs, PerfectNPC, PerfectSellChest and PerfectOneBlock keep working.
