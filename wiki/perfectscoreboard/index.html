PerfectScoreboard

A free HUD scoreboard for Hytale, built from an in-game visual editor with a live preview: 5 themes, your server logo, conditional lines, profiles per world and per permission, 5 screen positions.

Version2.0.0
PlatformHytale Server Plugin (Update 7)
Java21+
DependenciesNone (PerfectEconomy and PerfectJobs are optional: their placeholders work when they are installed)
PriceFree

Download on BuiltByBit (Free)

Installation

  1. Drop PerfectScoreboard-2.0.0.jar in mods/
  2. Start the server: the scoreboard shows on join
  3. Type /sb (admins) to build yours

Visual editor (/sb)

Admins (permission perfectscoreboard.admin) open the editor with /sb. Everything you change is a draft: Save applies it to every player, Cancel goes back. The preview uses the real theme, and your own board shows the draft live while you edit.

  • Lines: add, move, copy, delete (up to 15), 16 colour buttons, a clickable placeholder list, the condition of each line.
  • Look: theme, title, footer, position, animation, server logo.
  • Profiles: create, copy, worlds, permission, priority.
  • Settings: refresh speed, time zone, show on join, custom placeholders, Reload files.

Server logo

  1. Make a PNG (best: a wide image, 400 x 88 px; transparency is kept).
  2. Save it as logo.png in UserData/Saves/MODDING/mods/KatsuyaTV_PerfectScoreboard/
  3. Restart the server (the file is read once per start).
  4. Check "Show logo" in /sb > Look (per profile).

The logo is resized to fit, empty transparent edges are trimmed and the ratio is kept. It works in every theme. Without a file, a "YOUR LOGO HERE" placeholder is shown; a file that cannot be read (or is bigger than 20 MB, or fully transparent) is reported in the server log and in the editor, and the default logo is shown.

Conditional lines

Each line can be shown only:

  • in some worlds (arena_* works),
  • with a permission,
  • when a value matches, for example {eco_balance} > 1000 or {job_title} contains Master. Operators: = != > < >= <= and contains.

A "Not" switch inverts the condition. A hidden line takes no room.

Profiles

Each profile has its own title, lines, footer, theme, position, animation and logo setting. A profile can apply to some worlds and/or to a permission, and a priority decides which one wins when several match. The default profile is shown where no other matches.

Configuration

Folder: UserData/Saves/MODDING/mods/KatsuyaTV_PerfectScoreboard/ with config.json (language, refresh time, default profile, show on join, time zone, hidden players, custom placeholders) and profiles.json. Everything can be changed in /sb; /sb reload reads the files again.

{
  "lang": "EN",
  "refreshMs": 1000,
  "showOnJoin": true,
  "timezone": "UTC"
}

refreshMs goes from 250 to 10000.

Updating from 1.1

Replace the jar. Profiles, lines, worlds and settings are converted on the first start and the old files are copied to backups/before_2.0_<date>/. Converted profiles use the Classic theme; pick another in /sb > Look. A 1.1 profile "condition" (world:... / permission:...) is now applied.

FAQ

My logo does not show?

Check the file name (logo.png), the folder above, "Show logo" in /sb > Look, and restart the server: the logo is read once per start. The editor and the server log say what is wrong.

How do I use colour codes?

&a = green, &c = red, &e = yellow... or &#ff8800 for any colour.

Can players hide the scoreboard?

Yes, /sb toggle. The choice is remembered after a restart.

A player can type /sb but not open the editor?

The editor needs perfectscoreboard.admin.
